# Machine Learning Internship Tasks

This repository contains a set of **machine learning projects** designed for internship training.  
The tasks cover **supervised & unsupervised learning, regression, classification, and clustering**, using real-world datasets.

---

## Task 1: Student Score Prediction  
**Dataset:** [Student Performance Factors (Kaggle)](https://www.kaggle.com/)  
**Objective:** Predict students’ exam scores based on study hours  

- Perform data cleaning & visualization  
- Split into training/testing sets  
- Train a **Linear Regression model**  
- Visualize predictions & evaluate performance  

**Bonus:**  
- Apply **Polynomial Regression** and compare results  
- Try different feature combinations (e.g., sleep, participation)  

**Topics:** Regression | Evaluation Metrics  
**Libraries:** Python, Pandas, Matplotlib, Scikit-learn  

---

## Task 2: Customer Segmentation  
**Dataset:** [Mall Customer Dataset (Kaggle)](https://www.kaggle.com/)  
**Objective:** Cluster customers based on **income** and **spending score**  

- Data scaling & visualization  
- Apply **K-Means clustering**  
- Determine optimal clusters (Elbow / Silhouette)  
- Visualize results with 2D plots  

**Bonus:**  
- Experiment with **DBSCAN**  
- Analyze average spending per cluster  

**Topics:** Clustering | Unsupervised Learning  
**Libraries:** Python, Pandas, Matplotlib, Scikit-learn  

---

## Task 3: Forest Cover Type Classification  
**Dataset:** [Covertype (UCI)](https://archive.ics.uci.edu/ml/datasets/covertype)  
**Objective:** Predict forest cover type using cartographic & environmental features  

- Clean & preprocess data (categorical + numerical)  
- Train **tree-based multi-class classifiers** (Random Forest, XGBoost)  
- Evaluate with accuracy, precision, recall, F1-score  
- Visualize **confusion matrix & feature importance**  

**Topics:** Multi-class Classification | Tree-based Modeling  
**Libraries:** Python, Pandas, Scikit-learn, XGBoost
